# CVL_Assignment01

This repository contains an implementation of image enhancement techniques for Computer Vision coursework.

The project demonstrates enhancement on several types of images, such as:
- Blurred images
- Dark images
- Bright images
- Low-contrast images

The notebook includes image preprocessing, enhancement methods, and visualization of the results.

## Files

- `CVL_Assignment01.ipynb` — main notebook
- `dataset/` — sample images used for image enhancement experiments
